# Team Project

## 1. Clone the Project

Open **Git Bash** or the **VS Code Terminal** and run:

```bash
git clone https://github.com/Akash175P/team-project.git
```

Then enter the project folder:

```bash
cd team-project
```

## 2. Install Dependencies

Run:

```bash
npm install
```

This installs all the required project dependencies.

## 3. Start the Project

Run:

```bash
npm run dev
```

The terminal will display the local URL. Open that URL in your browser to view the project.

## Quick Start

```bash
git clone https://github.com/Akash175P/team-project.git
cd team-project
npm install

```
